# 📊 E-Commerce Sales Dashboard (Excel)

An interactive Excel dashboard built to analyze e-commerce sales performance using a 1,000-row synthetic dataset — designed to surface revenue trends, order patterns, and category-level insights at a glance.

## 📌 Project Overview

This project simulates a real-world business analytics task: taking raw transactional sales data and turning it into a clean, decision-ready dashboard. The goal was to practice core Excel analytics skills used by Data Analysts — PivotTables, KPI summarization, and multi-metric charting — while producing something visually presentable for a portfolio.

## 🎯 Objectives

- Clean and structure raw e-commerce sales data for analysis
- Summarize key business metrics (revenue, order volume, trends) using PivotTables
- Build a KPI card layout for quick-glance performance tracking
- Visualize multiple metrics together using dual-axis PivotCharts

## 🛠️ Tools & Techniques Used

| Tool / Technique | Purpose |
|---|---|
| Excel PivotTables | Summarizing sales by category, region, and time period |
| SUMIF / COUNTIF | Calculating conditional totals and order counts |
| PivotCharts (dual-axis) | Comparing metrics like revenue vs. order count on one chart |
| KPI Cards | Highlighting headline numbers (total revenue, total orders, avg order value, etc.) |
| Data Formatting | Structuring the raw dataset for reliable Pivot analysis |

## 📈 What's Inside

- **5 dynamic PivotTables** breaking down sales by relevant dimensions (e.g., product category, region, time)
- **KPI summary cards** for at-a-glance performance metrics
- **Dual-axis PivotCharts** to compare two related metrics (e.g., revenue and order volume) in a single visual
- A structured, recruiter-readable layout suitable for quick review

## 💡 Key Learnings

- How to structure raw data so PivotTables stay dynamic and error-free as the dataset changes
- Building dashboards that balance detail (PivotTables) with clarity (KPI cards)
- Using dual-axis charts effectively without misleading the viewer — a common analytics pitfall

## 🚀 How to Use

1. Download 'ecommerce_sales_dataset.xlsx' from this repository
2. Open in Excel (2016 or later recommended for full PivotChart support)
3. Explore the PivotTables — filters can be adjusted to slice the data differently
4. Review the KPI dashboard tab for a summary view
